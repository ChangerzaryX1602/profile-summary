# Career Summary — 1-Page A4 (ฟอร์มสรุปประสบการณ์สำหรับสัมภาษณ์ภายใน)

เว็บฟอร์มหน้าเดียว: กรอกประสบการณ์/ทักษะ/ผลงาน/เส้นทางที่อยากไป แล้ว **Export เป็น PDF ขนาด A4 หน้าเดียว**
พร้อมระบบ **ย่อฟอนต์และบีบระยะห่างอัตโนมัติ** เมื่อข้อมูลเยอะเกินหนึ่งหน้า

- 🌐 production: https://profile.mysterchat.com (public, `noindex,nofollow`)
- 🔒 **ข้อมูลไม่ออกจากเครื่องคุณ**: เก็บใน `localStorage` ของเบราว์เซอร์เท่านั้น ไม่มี backend ไม่มี analytics
  (ย้ายเครื่องใช้ปุ่ม *บันทึก JSON* / *นำเข้า JSON*; ใช้เครื่องส่วนกลางให้กด *ล้างข้อมูลในเครื่อง*)

## ใช้งาน

1. เปิดหน้าเว็บ → แท็บ **ไทย / EN** สลับภาษาที่จะกรอก (ต้องกรอกทั้งคู่ถ้าต้องการเอกสารสองภาษา)
2. ปุ่ม `TH » EN` ท้ายช่อง = คัดลอกค่านั้นไปช่อง EN, ปุ่ม *คัดลอกไทย » EN ทั้งชุด* = คัดลอกทั้งหมด
3. **Export PDF (A4)** → หน้าต่างพิมพ์ของเบราว์เซอร์ → เลือก "Save as PDF"

### หัวข้อในเอกสาร
ชื่อ–ตำแหน่ง–ทีม (ช่อง "สรุปสั้น 2 บรรทัด" ไม่บังคับ) → **01 โปรเจกต์เด่น** (เล่ารายละเอียดงาน/บทบาท —
**ไม่มีช่องตัวเลขผลลัพธ์** โดยตั้งใจ) → **02 ทักษะ** → **03 จุดแข็ง 3 ข้อ** → **04 ความสนใจ / เส้นทาง**
→ ช่องทางติดต่อ

ไม่มีรูปถ่าย · ไม่มีช่อง "ทีมเป้าหมาย" · **ไม่มี section ประสบการณ์ทำงาน** — ทั้งสามอย่างเป็นเจตนา เพราะผู้ฟังคือ
Head + HR ของบริษัทปัจจุบัน จึงไม่ต้องรู้ว่ามาจากไหน ให้ตีความจากข้อมูลที่ให้ไปเอง
(แก้/เพิ่มหัวข้อได้ที่ array `SECTIONS` ใน `src/index.html` — เลข 01– 04 ในเอกสารคำนวณอัตโนมัติตามลำดับที่ render)

### Auto save
- บันทึกลง `localStorage` อัตโนมัติทุกครั้งที่พิมพ์ (ดีเลย์ 200 ms) + flush ตอนสลับแท็บ/ปิด/ออกจากช่อง
- มุมขวาบนขึ้น **"บันทึกแล้ว HH:MM:SS"** ให้เห็นว่าบันทึกจริง — ถ้าขึ้นสีเตือนแปลว่าเบราว์เซอร์บล็อก
  (โหมดส่วนตัว) ให้ใช้ปุ่ม *บันทึก JSON* แทน
- หน้าที่ยังไม่ได้แก้อะไรจะไม่เขียนทับข้อมูล (dirty flag) → เปิดหลายแท็บพร้อมกันไม่อัปเดตกันมั่ว

### กฎการย่ออัตโนมัติ

| สถานการณ์ | พฤติกรรม |
|---|---|
| ข้อมูลพอดี | 100% |
| ล้นเล็กน้อย | ย่อฟอนต์ทีละ 2% ลงถึง **70%** + บีบระยะห่าง section (2 ระดับ) |
| ล้นแม้ย่อสุด | **ขึ้นแถบเตือน** บอกว่ายังล้นกี่ มม. + section ไหนกินพื้นที่มากสุด — **ไม่ตัดข้อมูลให้เอง** (ต้องตัดเอง) |

PDF ที่ได้เป็น **ข้อความเวกเตอร์** (คัดลอก/ค้นหาได้) และ**ฝังฟอนต์ IBM Plex Sans Thai** ไปในไฟล์ → เปิดเครื่องไหนก็หน้าตาเหมือนกัน

## โครงสร้างไฟล์

```
src/index.html     ← dev (อ้าง fonts/fonts.css ภายนอก)
fonts/fonts.css    ← ฟอนต์ฝัง base64 (4 subset หลัก + 2 patch face สำหรับ → » ฿ ← ↑ ↓ •)
build.py           ← inline ฟอนต์ → dist/index.html (ไฟล์เดียวจบ ไม่มี request ออกนอก)
dist/index.html    ← ไฟล์ที่ deploy จริง (~120 KB, 0 external requests)
tests/check_a4.py  ← เทสจริงด้วย Playwright: 4 เคส → PDF ต้องได้ 1 หน้า A4 เสมอ
Dockerfile         ← nginx:alpine เสิร์ฟไฟล์เดียว
```

## พัฒนา / เทส

```bash
python3 build.py                 # สร้าง dist/index.html
pwpy tests/check_a4.py           # เทส PDF A4 จริง (ต้องมี pwpy = playwright python)
```

`tests/check_typing.py` = **เทสการพิมพ์จริง** (กันบั๊ก "refresh แล้วข้อมูลหาย"): พิมพ์ลงช่องจริงทุกชนิด
(ช่องธรรมดา + รายการซ้ำอย่างประสบการณ์/โปรเจกต์) แล้ว assert ว่า preview อัปเดตทันที, localStorage เก็บครบ,
และ **reload แล้วไม่หาย** — บทเรียน: การยิงข้อมูลผ่าน localStorage ตรง ๆ ซ่อนบั๊ก binding ได้ ต้องพิมพ์จริงเท่านั้น

`tests/check_live.py` = เทสเว็บจริงที่ deploy แล้ว (`pwpy tests/check_live.py`): HTTP 200 ผ่าน Cloudflare,
หน้าโหลด 0 request ออกนอก, ข้อมูลลง localStorage, และ PDF จากเว็บจริง = 1 หน้า A4 ฟอนต์ฝังครบ

`tests/check_a4.py` ตรวจ 4 เคส: ว่าง / ข้อมูลตัวอย่าง (ไทย+EN) / ล้นเกิน 70% / อักขระพิเศษ (฿ → » • ← ↑ ·)
เกณฑ์ผ่าน: **PDF = 1 หน้า A4**, ข้อความคัดลอกได้, **ไม่มีฟอนต์ระบบหลุดเข้าไปใน PDF**, ไม่มี console error

## Deploy

Dokploy (home server) → static app จาก repo นี้ (buildType `dockerfile`, port 80) → โดเมน `profile.mysterchat.com`
- Dokploy: project `profile-summary` → application `career-summary` (`8P_N7YRjVVc6Nn45M-fwM`), appName `profile-summary-4afnsy`
- DNS: CNAME `profile` → `ca17f740-9321-4176-b767-c50136830229.cfargotunnel.com` (tunnel "server", proxied)
- Tunnel ingress: `profile.mysterchat.com → https://192.168.1.105:443` (originServerName ตั้งเป็น host นี้)
- ไม่มี CF Access (public ตามที่เลือกไว้) — ถ้าอนาคตต้องการปิด ให้เพิ่ม Access app ที่โดเมนนี้แล้วเปิด policy email
